> Új projekt — a leírás még kitöltésre vár.

## Állapot

Kezdeti váz. A projekt céljának, technológiai stackjének és felépítésének
véglegesítése folyamatban.

## Felépítés

```
index.html     belépési pont
css/           stílusok
js/            szkriptek
assets/        képek, videók, betűtípusok

python3 -m http.server 8000
```
